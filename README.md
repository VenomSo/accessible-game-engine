# Accessible Game Engine

A unified game engine combining Roblox, Fortnite, and Rocket League gameplay with comprehensive accessibility features.

## Features

### Game Modes
- **Roblox**: Sandbox gameplay with user-created content
- **Fortnite**: Battle royale with building mechanics
- **Rocket League**: Soccer with rocket-powered cars

### Accessibility Features
- ✅ Captions & Subtitles
- ✅ Audio Descriptions
- ✅ Screen Reader Support
- ✅ Color Blind Modes
- ✅ High Contrast Mode
- ✅ Adjustable Text Sizes
- ✅ Keyboard Navigation
- ✅ Accessible Movies with Synchronized Captions

## Quick Start

```bash
git clone https://github.com/VenomSo/accessible-game-engine.git
cd accessible-game-engine
npm install
npm run dev
```
